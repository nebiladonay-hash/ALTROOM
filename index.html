One-time connection

Connect your room.

ALTROOM needs its own free Supabase project to keep accounts and conversations synced across devices. These settings stay in this browser. Use only your project's public anon/publishable key — never a service-role key.

  1. Create a free Supabase project.
  2. Open its SQL Editor, paste the contents of setup.sql, replace the placeholder invite code first, and run it.
  3. Copy the project URL and public anon/publishable key from Project Settings → API.

The preview is for design testing only. It will not send messages to other people.
